# Cookbook — as receitas mudaram de lugar

As receitas que moravam nesta página ganharam **uma página cada** na seção
[Receitas](recipes/index.md). Cada uma agora segue o formato completo: a situação real,
o código arquivo por arquivo, a explicação pedaço por pedaço, os estados da tela
(carregando, vazio, erro, celular) e um Recap. 🚚

Os títulos abaixo continuam aqui para que links antigos, como
`cookbook.md#fluxo-de-autenticacao-completo`, ainda caiam no lugar certo.

➡️ [Fluxo de autenticação completo](recipes/auth-flow.md): login, rotas protegidas e
sessão que expira sozinha.

## Offline-first

➡️ [Offline-first](recipes/offline-first.md): IndexedDB por usuário, sincronização que

## Paleta de comandos ⌘K
