    Command palette ⌘K

    Loja Aurora's dashboard grew: Pedidos, Clientes, Produtos, Relatórios, Equipe, Configurações. The manager spends the whole day in it and does not want to hunt for menu items. She presses ⌘K (or Ctrl+K on Windows), types "cli", hits Enter and she is in Clientes. On a phone, where there is no shortcut, a button at the top opens the same palette. ⌨️

    The pieces are the Command component, the useKeyboardShortcut hook, useNavigate from routing and Kbd to show the shortcut.

    Before you start

    This recipe uses the useAuth store from the Full authentication flow recipe and the ThemeProvider that already ships in <AppProviders>. Install in manual install.

    What we are building

    • ⌨️ ⌘K / Ctrl+K opens the palette from any screen, even with the focus in a field.
    • 🔎 Search by name and by synonym ("painel" finds "Início").
    • 🗂️ Groups: Navegação, Ações and Preferências.
    • 🔐 Items per role: only the manager sees "Equipe".
    • 📱 A button at the top with the shortcut hint, which is the way in on phones.

    The code

    // src/components/CommandPalette.tsx
import { useState } from "react";
import {
  Button,
  Command,
  Kbd,
  useKeyboardShortcut,
  useNavigate,
  useTheme,
  type CommandItem,
} from "tempest-react-sdk";
import { useAuth } from "@/stores/auth";

const isApple: boolean =
  typeof navigator !== "undefined" && /Mac|iPhone|iPad/.test(navigator.userAgent);

export function CommandPalette() {
  const [open, setOpen] = useState<boolean>(false);
  const navigate = useNavigate();
  const { toggle } = useTheme();
  const role: string | undefined = useAuth.use.user()?.role;
  const logout: () => void = useAuth.use.logout();

  useKeyboardShortcut(
    { key: "k", mod: true },
    (event) => {
      event.preventDefault();
      setOpen(true);
    },
    { ignoreInput: false },
  );

  const items: CommandItem[] = [
    {
      id: "home",
      label: "Início",
      group: "Navegação",
      keywords: ["painel", "dashboard"],
      onSelect: () => navigate("/"),
    },
    {
      id: "orders",
      label: "Pedidos",
      group: "Navegação",
      keywords: ["vendas", "compras"],
      onSelect: () => navigate("/pedidos"),
    },
    {
      id: "customers",
      label: "Clientes",
      group: "Navegação",
      keywords: ["compradores", "cpf"],
      onSelect: () => navigate("/clientes"),
    },
    {
      id: "new-order",
      label: "Novo pedido",
      group: "Ações",
      keywords: ["venda", "balcão"],
      onSelect: () => navigate("/pedidos/novo"),
    },
    {
      id: "theme",
      label: "Alternar tema claro/escuro",
      group: "Preferências",
      keywords: ["dark", "noturno"],
      onSelect: () => toggle(),
    },
    {
      id: "logout",
      label: "Sair",
      group: "Preferências",
      keywords: ["logout", "deslogar"],
      onSelect: () => {
        logout();
        navigate("/login", { replace: true });
      },
    },
  ];

  if (role === "gerente") {
    items.splice(3, 0, {
      id: "team",
      label: "Equipe",
      group: "Navegação",
      keywords: ["usuários", "acessos"],
      onSelect: () => navigate("/equipe"),
    });
  }

  return (
    <>
      <Button
        variant="outline"
        size="sm"
        onClick={() => setOpen(true)}
        rightIcon={<Kbd size="sm">{isApple ? "⌘ K" : "Ctrl K"}</Kbd>}
      >
        Buscar
      </Button>
      <Command
        open={open}
        onOpenChange={setOpen}
        placeholder="Ir para tela ou ação…"
        emptyMessage="Nada encontrado. Tente outro termo."
        items={items}
      />
    </>
  );
}

import { Outlet } from "tempest-react-sdk";
import { CommandPalette } from "@/components/CommandPalette";

export function PrivateLayout() {
  return (
    <div>
      <header
        style={{
          display: "flex",
          justifyContent: "space-between",
          alignItems: "center",
          gap: 12,
          padding: "12px 16px",

        }}
      >
        <strong>Loja Aurora</strong>
        <CommandPalette />
      </header>
      <main style={{ padding: 16 }}>
        <Outlet />
      </main>
    </div>
  );
}

    Piece by piece

    Command does the heavy lifting

    You hand over a list of CommandItems and control open / onOpenChange. The rest is its job:

    • it filters the items by a piece of the text in label and in keywords, case-insensitive;
    • it groups the results by group, in the order the groups appear in the list;
    • it navigates with ↑ / ↓, runs with Enter and closes on Escape, click outside or selection;
    • it traps the focus inside the palette while it is open.

    Each onSelect is the item's action: navigate(...), toggle() or logout().

    keywords is where usability lives

    Nobody remembers whether the screen is called "Clientes" or "Compradores". Put the synonyms in keywords, including words without accents ("usuarios") if your team types like that: the search compares the text as it is, accents included.

    The shortcut works on any system

    useKeyboardShortcut({ key: "k", mod: true }, handler) matches Cmd+K on macOS and Ctrl+K on Windows and Linux. The hook takes a KeyboardShortcut object, not a string.

    Two details make the shortcut ready for real use:

    • event.preventDefault(): Ctrl+K is a browser shortcut of its own (focus the search in Chrome and Firefox). Without it, the palette opens and the browser steals the focus.
    • { ignoreInput: false }: by default the hook ignores keys typed inside a field, so it does not hijack typing. For ⌘K that is the opposite of what you want: the person has the focus in the orders search and wants to jump screens. Since the shortcut needs the modifier, there is no risk of swallowing a typed letter.

    Items per role

    The list is built during render, so it can depend on the user. Here, "Equipe" only goes in for role === "gerente". Hiding the item does not protect the route: the /equipe guard and the backend remain responsible for access. See Access control.

    The button with Kbd

    The "Buscar" (search) button has two roles. On a computer, it teaches the shortcut, with the right key for the system in use. On a phone, it is the only way to open the palette, since there is no physical keyboard. 📱

    Why detect the platform by hand

    The hook's mod resolves Cmd vs. Ctrl when listening for the key. To show the key, the app decides on its own, and a test on navigator.userAgent is enough. The typeof navigator check avoids an error if the module is imported outside the browser, in a Node test, for example.

    Recap

    • ✅ Command takes items, open and onOpenChange and handles search, groups, keyboard and focus.
    • ✅ useKeyboardShortcut({ key: "k", mod: true }, …, { ignoreInput: false }) opens the palette from anywhere, with preventDefault to beat the browser's shortcut.
    • ✅ keywords finds the screen by synonym.
    • ✅ The list depends on the user, but the real protection lives in the guard and the backend.
    • ✅ A button with Kbd teaches the shortcut and is the way in on phones.
